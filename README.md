A memory scanner for linux, built in c.
(WIP)
## Setup

### Requirements
- ncurses

Clone the repository:
```bash
git clone https://github.com/SuperUserDo415/memoryScanner.git
```

Run:
```bash
gcc scanner.c -o scanner.out -lncurses && ./scanner.out
```
